# 検証可能な学習ログ

学位や資格の代わりに、**改ざんできない学習記録**で信用を作るための道具。
学習を1件記録するたびに、直前の記録のハッシュを含めてチェーン化するので、
後から記録を書き換える・消す・並べ替えると検証で検出される。
依存ライブラリなし（Python標準ライブラリのみ）。記録は手元のファイルだけで完結し、外部送信はない。

## 使い方

```bash
# 学習を記録する（成果物ファイルがあればハッシュも一緒に記録）
python3 log.py add "RAGのk掃引を実測し欠落項目を数えた" --min 90 --tag rag --file out_k3.txt

# 溜まっていた過去の成果物を一括登録（「事後登録」と明示される）
python3 log.py backfill ~/Downloads --ext .txt

# 検証
python3 log.py verify

# 提出用レポート（単一HTML）を生成
python3 log.py report
```

## 信頼モデル（ここが肝）

このチェーンが保証するのは「**各記録が、記録した時点以降改ざんされていないこと**」であり、
学習した日付そのものの真実性ではない。だから:

- 過去の成果物の一括登録は `backfill` として**必ず区別して記録**され、レポートにも明示される
- 学習時間の集計に事後登録分は**含めない**
- 成果物ファイルのSHA-256を記録するので、「この時点でこのファイルを持っていた」ことは示せる

証明できることと、できないことを分けて示す——この正直さが、
第三者がこの記録を信用できる唯一の根拠になる。

## 出力

`report.html` は自己完結の1ファイル。期間・タグ別の学習時間・成果物ハッシュ・
チェーン検証結果をまとめた「学習経歴書」として、応募や提案に添付できる。
受け取った側は `learning-log.jsonl` と `log.py` があれば検証を再実行できる。
