# 検証可能な学習ログ

資格や学歴だけでは示しにくい学習の積み重ねを、**改ざんを検出できる形**で記録するためのツールです。学習を1件記録するたびに、直前の記録のハッシュを含めてチェーン状につなげるため、後から記録を書き換えたり、消したり、並べ替えたりすると、検証時に検出されます。追加の依存ライブラリはなく、Python標準ライブラリだけで動きます。記録は手元のファイルだけで完結し、外部への送信はありません。

## 使い方

```bash
# 学習を記録する（成果物ファイルがあればハッシュも一緒に記録）
python3 log.py add "RAGのk掃引を実測し欠落項目を数えた" --min 90 --tag rag --file out_k3.txt

# 溜まっていた過去の成果物を一括登録（「事後登録」と明示される）
python3 log.py backfill ~/Downloads --ext .txt

# 検証
python3 log.py verify

# 提出用レポート（単一HTML）を生成
python3 log.py report
```

## 何を証明できるか

このチェーンで示せるのは「**各記録が、記録された時点以降に改ざんされていないこと**」です。学習した日付そのものが正しいことまでは示せません。そのため、次のように扱いを分けています。

- 過去の成果物の一括登録は `backfill` として**通常の記録と区別して記録**され、レポートにも明示されます
- 学習時間の集計には、事後登録分を**含めません**
- 成果物ファイルのSHA-256を記録するため、「この時点でこのファイルを持っていた」ことは示せます

証明できることとできないことを分けて示すことで、第三者が記録の意味を正しく判断できるようにしています。

## 出力

`report.html` は自己完結した1ファイルです。期間・タグ別の学習時間、成果物のハッシュ、チェーンの検証結果をまとめた「学習経歴書」として、応募や提案の際に添付できます。受け取った側は、`learning-log.jsonl` と `log.py` があれば検証を再実行できます。
