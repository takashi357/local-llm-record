# 支給端末クラスの機体で、どのモデルが実用になるか

CF-FV（WSL＋Ollama）でのモデル比較の記録。

本リポジトリのツールは gpt-oss-20b（12.11GB）を前提としている。
では、職場で配られる標準的なノートPCでこのツールは動くのか。
その前提条件を確定させるために、機体の制約と、その制約下で動くモデルの実力を測った。

## 結論

1. メモリ16GBの端末に Windows 経由で Linux を立てると、割当は既定で 7.6GB。
   本ツールが要求する 12.11GB のモデルは、この既定値では読み込めない。
2. 7.6GB の枠内でも、モデルを選べば実用速度と自然な日本語は両立する。
   ただし容量の大小と速度・品質は比例しない。3.3GB のモデルが 5.2GB のモデルより
   約 2 倍速く、日本語も自然だった。
3. 品質の高いモデルほど、誤りが検出されにくくなる。
   最も日本語が自然だったモデルが、根拠のない金額を出力した。

## 測定環境

| 項目 | 値 |
|---|---|
| OS | Windows 11 |
| Linux 実行環境 | WSL 2.7.12 + Ubuntu 26.04 LTS |
| メモリ | 16.0GB LPDDR4-4267（うち WSL 割当 7.6GB、swap 2.0GB） |
| GPU | Intel Iris Xe（内蔵。専用 VRAM なし） |
| 推論エンジン | Ollama |
| 測定日 | 2026-08-23 |

専用グラフィックボードは搭載していない。推論はCPU中心で行われる。

## 設問

```
納付書を紛失したという問い合わせに対する窓口回答を、敬語で3文以内で書いてください。
```

同一設問を各モデルに 3 回投入した。パラメータは既定値のまま変更していない。

qwen3 は回答の前に推論過程を英語で出力する仕様のため、出力トークン数が増え、

各モデルとも 1 回目のみモデル読み込み時間が加算される（qwen3 で 9.42 秒、
gemma3 で 5.59 秒）。連続実行時の 2 回目以降はミリ秒単位に収まる。
測定時は 1 回目を除外するのが妥当。

## 所見

### 生成速度は安定、総所要時間は不安定

生成速度は同一モデル内でほぼ一定である。gemma3 は 12.31 / 12.30 / 12.33 tok/s と
3 回でほぼ完全に一致した。一方、総所要時間は 3.8〜10.8 秒とばらつく。
原因は出力の長さであり、処理速度ではない。

所要時間で閾値を設ける運用は、出力長の変動をそのまま受けることになる。

### 3 文以内という指示は、全モデルで守られなかった

| モデル | 3 文以内の遵守 |
|---|---|
| llama3.2:3b | 3 回中 2 回 |
| gemma3:4b | 3 回中 0 回（全回 4 文） |
| qwen3:8b | 3 回中 1 回 |

日本語として最も自然だった gemma3 が、字数・文数の制約は最も守っていない。
文体の品質と指示追従は別の軸である。

### 日本語の破綻（llama3.2:3b）

- 「ごみ箱などに捨てられている可能性がありますようになります。ごみ箱の確認をしてみてください。」
- 「ご紛失になったためご迷惑をおかけしたことを sincerest apologies で表します。」（英語混入）
- 「弊社」「直営店」など、行政窓口ではなく企業応対の語彙

この水準の出力は、読めば誤りと分かる。

### 根拠のない事実の生成（gemma3:4b）

1 回目の出力に、次の一文が含まれた。

> 再発行の手続きにつきましては、手数料300円をご負担いただきます。

設問に金額の情報は含まれていない。300 円という数値の根拠は存在しない。

敬語は正しく、文の運びも自然で、内容も窓口回答として成立して見える。
破綻した日本語であれば誰でも捨てられるが、この種の誤りは
原典と照合しなければ検出できない。

3 回目には「お支払いの銀行または関係部署までお問い合わせください」（qwen3）という
案内先の誤りも出ている。納付書の再発行は発行元の窓口が扱う事務であり、
銀行の所管ではない。

金額・期限・所管部署を含む出力は、原典照合の工程を通さない限り
そのまま使用できない。本リポジトリのツールが照合を目的としているのは、
この性質に対応するためである。

## 検証の限界

- 設問は 1 種類のみ。文書要約や抽出など、他の作業では傾向が異なる可能性がある
- 各 3 回のみ。統計的な有意性を主張できる回数ではない
- 機体は 1 台のみ。CPU 世代・メモリ帯域が異なれば速度は変わる
- 量子化形式は Ollama の既定値に依存しており、モデル間で条件が完全に揃っていない
- 出力の良否は筆者の判断による。第三者による評価は行っていない
